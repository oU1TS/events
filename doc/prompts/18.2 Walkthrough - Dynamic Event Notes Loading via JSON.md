# Walkthrough - Dynamic Event Notes Loading via notes.json

We have transitioned the Event Notes section (`#notes-container` at `index.html:L356`) to asynchronously load all delegation writeups, directories, and guides from a dedicated `notes.json` file located at the repository root, mirroring the asynchronous loading, caching, skeleton loaders, and download export architecture of `raids.json`.

---

## 🛠️ Changes Implemented

### 1. Dedicated `notes.json` Dataset
Created [`notes.json`](notes.json) cataloging all markdown documents in `doc/notes/`:
- **Phoenix Summit 2026 Delegation Notes** (`doc/notes/phoenix-summit-2026.md`, linked to Raid #1)
- **AMD Developer Hackathon: ACT II** (`doc/notes/amd-dev-hackathon-2026.md`, linked to Raid #2)
- **NSU MarXcellence 2026 Delegation Notes** (`doc/notes/MarXcellence-2026.md`, linked to Raid #3)
- **Competitions for CSE Students of Bangladesh** (`doc/notes/competitions.md`, Curated Directory)
- **Event Trackers & Developer Competitions Master Directory** (`doc/notes/event_trackers_directory.md`, Master Directory)

Each entry contains:
```json
{
  "id": "phoenix-summit-2026",
  "title": "Phoenix Summit 2026 Delegation Notes",
  "category": "Conference Notes",
  "description": "UITS Event Raiders delegation notes, safety guidelines, industry senior advice (Rezwan bhai), and technical session highlights covering cybersecurity, Blue/Red teaming, and Wazuh detection.",
  "file": "doc/notes/phoenix-summit-2026.md",
  "raidNum": 1,
  "tags": ["Cybersecurity", "Blue Team", "Red Team", "Wazuh", "Delegation Notes", "Career Advice"],
  "lastUpdated": "2026-06-27"
}
```

### 2. Markup Updates in [`index.html`](index.html)
- Added an action bar in `#notes` with a **"Download notes.json"** button (`#download-notes-json-section-btn`).
- Seeded `#notes-container` with shimmer skeleton loader cards (`<div class="resource-card skeleton"></div>`) so users experience smooth visual feedback while data loads.

### 3. Application Logic in [`app.js`](app.js)
- **State Variables**: Added `eventNotesData` and `isNotesLoading`.
- **Asynchronous Loader**: Added `loadEventNotes(options = {})` fetching `notes.json` with cache-bypassing (`forceFresh`) support and error resilience (`renderNotesError`).
- **Enhanced Card Renderer (`renderEventNotes`)**:
  - Dynamically builds resource cards with category badges (`note-category-badge`), campaign badges (`Raid #N`), titles, descriptions, and tag pills.
  - Generates action links: "View Notes" (`render.html?file=...`) and "View Campaign" (`#raid-<N>`).
  - Cross-references any dynamic `links.notes` from `pastRaidsData` or approved database proposals, ensuring custom notes are included without duplicating entries present in `notes.json`.
- **Export Utility**: Implemented `downloadNotesJsonFile()` bound to `#download-notes-json-section-btn`.
- **Lifecycle Integration**: Integrated `loadEventNotes()` into `initCacheAndNotifications()` (startup parallel fetch via `Promise.allSettled`) and the SPA hash router (`#notes`).

### 4. Styling Polish in [`style.css`](style.css)
- Added `.resource-card.skeleton` min-height rule (`220px`).
- Styled `.note-header-badges`, `.note-category-badge`, `.note-raid-badge`, `.note-tags-container`, and `.note-tag`.

### 5. Documentation Maintenance
- Updated [`documentation.md`](documentation.md) with the **v1.17.0** release changelog and architecture tree.
- Updated [`learning.md`](learning.md) detailing the asynchronous data layer and note cross-referencing mechanics.
- Updated [`README.md`](README.md) listing the `notes.json` dataset and export feature.
