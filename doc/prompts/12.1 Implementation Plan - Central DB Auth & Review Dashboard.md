# Implementation Plan: 12. Central Database Authentication, Event Update Proposals & Review Dashboard

Integrate the centralized Supabase database from `ou1ts.github.io` into `events`, enabling authentication, profile synchronization, role management (admin/mod), community event proposals, and a review console with `raids.json` compilation tools.

---

## 1. Database Layer & Schema Migrations
- **File**: `doc/db/event_raids_schema.sql`
- **Tables**:
  - `public.event_roles`: Stores project roles (`admin`, `mod`, `user`), foreign keyed to `auth.users(id)`.
  - `public.event_submissions`: Stores new proposals and edits to `raids.json` entries with statuses: `'pending'`, `'approved'`, `'rejected'`.
- **Security & RLS**:
  - Security-definer helper functions: `is_event_admin()`, `is_event_staff()`.
  - Authenticated users can insert proposals and view own proposals.
  - Staff (admins and mods) can view all proposals and update status.
  - Admins can manage mod assignments in `event_roles`.

---

## 2. Environment Configuration
- **File**: `env-config.js`
- Sets `window.__ENV` with `SUPABASE_URL` and `SUPABASE_ANON_KEY` matching `ou1ts.github.io`.

---

## 3. UI Markup & Modal Hierarchy
- **File**: `index.html`
- **Head Integration**: Loads `env-config.js` and `@supabase/supabase-js@2`.
- **Navigation Elements**:
  - Desktop floating button: `#desktop-auth-btn` positioned at bottom-left.
  - Mobile sidebar button: `#mobile-auth-btn` inside `#main-nav` at the bottom.
- **Modals**:
  - `#auth-modal`: Login, Registration (with student ID, department, blood group), Password Recovery.
  - `#dashboard-modal`: Profile details, role badges, action tiles, Log Out button.
  - `#event-form-modal`: Raid submission form with dynamic sub-events repeater and official links.
  - `#review-dashboard-modal`: Filter tabs, diff comparison cards, approve/reject buttons, Download/Copy raids.json.
  - `#mod-management-modal`: Community member list, search input, Mod assign/revoke toggles.

---

## 4. CSS Design System & Theme Alignment
- **File**: `style.css`
- Glassmorphic modal backdrops, scale/fade cubic-bezier animations.
- Responsive breakpoints: desktop floating button hidden on `< 768px`, mobile sidebar auth shown on `< 768px`.
- High-contrast role badges (`role-admin`, `role-mod`, `role-user`).
- Visual diff tables with green additions and red deletions.

---

## 5. JavaScript Application Controller
- **File**: `app.js`
- Initializes Supabase client and registers `onAuthStateChange` listener.
- Syncs auth state: resolves profile and project role, adapts button labels and badges.
- Injects "✏️ Edit" button on each raid card summary for logged-in members.
- Handles proposal submission, real-time diff generation, review approvals, in-memory updates, and `raids.json` file downloads.
- Admin moderator search and role assignment toggles.
