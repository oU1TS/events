# Implementation Plan - Past Raids Toggle & Auto-Unhide

Add a toggle button to the "Past Raids & Future Campaigns" section to control the visibility of past raids (hidden by default). If a user accesses a specific past raid using a deep-link URL (e.g., `#raid-1`), past raids will automatically be unhidden so the target card can be displayed and scrolled to.

## Proposed Changes

- Add `#toggle-past-raids-btn` into `.calendar-btn-container` alongside the Calendar View button and Event Type filter dropdown.
- Initial state button text: "Unhide Past Raids" with eye icon.

### [JavaScript Controller]

#### [MODIFY] [app.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/events/app.js)
- Add state variable `showPastRaids = false`.
- Implement `isPastRaid(raid)` helper to determine if a raid's status is "Past" (either by `raid.Status === 'Past'` or comparing current date against `raid.endDate`).
- Update `filterAndRenderRaids()` to filter out past raids when `showPastRaids` is `false`.
- Create `initPastRaidsToggle()` and `updatePastRaidsToggleUI()` functions to update toggle button text, icon (eye vs eye-off), and active class when toggled.
- Update `routePage()` and `loadPastRaids()` deep-linking logic so that accessing a past raid URL (`#raid-<number>`) sets `showPastRaids = true`, updates the toggle UI to "unhide", renders the raids, and scrolls to the card.

## Verification Plan

### Manual Verification
1. **Default View**:
   - Open `#raids` section without a raid hash. Verify past raids (e.g., Raid 1 Phoenix Summit) are hidden by default.
   - Verify toggle button shows "Unhide Past Raids".
2. **Toggle Button Click**:
   - Click "Unhide Past Raids". Verify past raids appear and button label changes to "Hide Past Raids" with active highlight styling.
   - Click again to verify past raids are hidden.
3. **Deep Link via URL**:
   - Navigate to `index.html#raid-1` (a past raid).
   - Verify past raids are automatically unhidden, the toggle button reflects the "Unhide" state ("Hide Past Raids"), and the page scrolls directly to Raid 1 card with border highlight animation.
   - Navigate to `index.html#raid-13` (a future raid).
   - Verify past raids remain hidden, only future raids render, and Raid 13 is scrolled into view.
