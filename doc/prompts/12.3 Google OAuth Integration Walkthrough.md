# 12.3 Walkthrough - Google OAuth Authentication Integration

## Overview
This walkthrough details the integration of Google OAuth sign-in into the UITS Event Raiders portal, connected to the central Supabase backend (`ou1ts.github.io`).

---

## Changes Implemented

### 1. UI Markup (`index.html`)
- Added `#oauth-divider` (`"or continue with"`) with centered typography and separator rules.
- Added `#google-login-btn` containing the official multi-color Google 'G' SVG icon and descriptive text (`"Continue with Google"`).
- Automatically hidden when the user selects the "Forgot Password" tab and restored for "Login" and "Register" tabs.

### 2. Styling (`style.css`)
- Styled `.auth-divider` with subtle line rules and theme-adaptive muted text.
- Styled `.oauth-btn` with glassmorphic obsidian/light backgrounds, hover elevation (`translateY(-2px)`), and gold accent border glow.
- Added `.google-icon` sizing and responsiveness.

### 3. Client Logic (`app.js`)
- **OAuth Trigger**: Integrated `supabaseClient.auth.signInWithOAuth({ provider: 'google', options: { redirectTo } })`.
- **Environment & Protocol Validation**: Added an explicit guard to verify `window.location.protocol !== 'file:'`, prompting the developer/user to run via an HTTP/HTTPS server (e.g. Live Server or hosted on GitHub Pages) if opened as a local file.
- **Callback URL Cleanup**: In `onAuthStateChange`, automatically detects OAuth redirect parameters (`#access_token=...` or `?code=...`) and replaces the URL state with a clean path (`window.history.replaceState`), eliminating residual token hashes.
- **User Metadata & Avatar**: Extracts Google user profile metadata (`avatar_url` or `picture`, `full_name`, `email`) and renders the user's avatar image inside `#dash-avatar` with graceful fallback to monogram initials.
- **Project Tag Sync**: Automatically ensures the user's central profile is tagged with `'events'` upon initial Google sign-in.

## Supabase Configuration Instructions (For Project Admins)

To ensure Google OAuth works seamlessly in production and local environments:

1. **Google Cloud Console**:
   - Go to [Google Cloud Console Credentials](https://console.cloud.google.com/apis/credentials).
   - In your OAuth 2.0 Client ID, add the Supabase Auth Callback URL to **Authorized redirect URIs**:
     ```text
     https://bennnocwssmcpiqradvc.supabase.co/auth/v1/callback
     ```

2. **Supabase Dashboard**:
   - Navigate to **Authentication** > **Providers** > **Google**.
   - Enable Google provider.
   - Enter your **Client ID** and **Client Secret** from Google Cloud Console.
   - Under **Authentication** > **URL Configuration**, add your production and local origins to **Redirect URLs**:
     ```text
     http://localhost:3000
     http://localhost:5500
     http://127.0.0.1:5500
     https://ou1ts.github.io/events/
     ```
