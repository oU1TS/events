# Implementation Plan: 15. Calendar Initial Month & Approved Raid Persistence

Address the calendar modal defaulting to July instead of the current month and resolve approved proposal persistence so that approved database additions are retained across page reloads.

---

## Proposed Changes

### 1. Calendar Initial Month Fix
- **File**: [`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js)
- **Problem**: In `initCalendar()`, `calendarYear = 2026; calendarMonth = 6;` was hardcoded to July. Also, `openModalWithData()` didn't reset the calendar month/year to the current date when triggered.
- **Solution**:
  - Dynamically initialize `calendarYear` and `calendarMonth` using `new Date()`.
  - In `openModalWithData()`, reset `calendarYear` and `calendarMonth` to the current system date so clicking `#open-calendar-btn` or `#floating-calendar-btn` consistently opens the active current month.

### 2. Database Approved Raid Persistence & Live Synchronization
- **File**: [`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js)
- **Problem**: Approving a submission in the Review Dashboard updated Supabase and placed the new raid in browser memory (`pastRaidsData`). On page reload, `loadPastRaids()` solely fetched static `raids.json` without retrieving or merging approved submissions from the database, causing approved raids to vanish upon refresh.
- **Solution**:
  - Implement `applyApprovedSubmissionsToDataset(submissions)` to cleanly merge approved items into `pastRaidsData` (updating existing or prepending new) and sorting by `Raid_Num` descending.
  - Implement `syncApprovedSubmissionsFromDatabase()`:
    - Immediately applies cached approved submissions from `localStorage` (`event_raids_approved_cache`) to prevent visual flash or delay on page load.
    - If `supabaseClient` is initialized, queries `event_submissions` for `status = 'approved'`, updates `event_raids_approved_cache`, merges them into `pastRaidsData`, and triggers re-render of raids, calendar, and notes.
  - Call `syncApprovedSubmissionsFromDatabase()` in:
    - `loadPastRaids()` right after parsing `raids.json`.
    - `syncAuthState()` when the user's session is initialized or changed.
  - Update `approveSubmission()` to write approved records to `event_raids_approved_cache`.
  - Update `rejectSubmission()` to remove rejected records from `event_raids_approved_cache` if previously approved.
  - Expose `window.renderCalendarGrid` from `initCalendar()` so calendar dates update reactively when database submissions arrive.
