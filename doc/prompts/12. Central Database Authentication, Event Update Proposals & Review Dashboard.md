### Thinking Process

1. **Investigate Database Architecture**:
   - Examined `D:\GitHub\[oU1TS]\ou1ts.github.io` and discovered central Supabase connection credentials (`env-config.js`) with shared `public.profiles` schema.
   - Identified required schemas: `profiles` contains `full_name`, `student_id`, `department`, `batch`, `blood_group`, `project_tags`.
2. **Design Project-Scoped Roles and Submissions**:
   - Designed `public.event_roles` table for project permissions: `admin`, `mod`, `user`.
   - Designed `public.event_submissions` table for proposal management with statuses: `pending`, `approved`, `rejected`.
   - Formulated security-definer functions `is_event_admin` and `is_event_staff` to prevent infinite RLS recursion.
3. **Frontend Componentry & Modal Architecture**:
   - **Desktop Floating Button**: Fixed position pill button (`#desktop-auth-btn`) with glassmorphism, accent borders, and hover micro-animations. Toggles from "Login" to "Dashboard" with member avatar.
   - **Mobile Sidebar Button**: Placed at the very bottom of `#main-nav` (`#mobile-auth-btn`) with `margin-top: auto` in flex layout.
   - **Auth Modal (`#auth-modal`)**: Tabbed interface for Sign In, Registration (mapping student ID, department, blood group), and Password Recovery.
   - **Dashboard Modal (`#dashboard-modal`)**: User profile badge, quick action to propose raids, staff action to Review Dashboard, admin action to Mod Management, and Log Out button.
   - **Event Proposal Modal (`#event-form-modal`)**: Complete raid specification form matching `raids.json` with sub-events repeater, date range/start/end/deadline inputs, online/outside-Dhaka flags, and links.
   - **In-Card Suggest Edit Button**: Injected "✏️ Edit" button onto each card for logged-in members.
   - **Review Dashboard (`#review-dashboard-modal`)**: Role-gated review console with status filters, side-by-side diff comparisons, one-click Approve/Reject actions, and 1-click "Download raids.json" / "Copy JSON" export tools.
   - **Moderator Management Modal (`#mod-management-modal`)**: Searchable community member list with Promote to Mod / Demote to User toggles.
4. **Theme Adherence**:
   - Built with identical CSS design tokens: obsidian dark mode (`#07080b`), gold/amber cyber accents (`#d4af37`), frosted glass backdrop blurs (`backdrop-filter: blur(12px)`), and light theme variables.
