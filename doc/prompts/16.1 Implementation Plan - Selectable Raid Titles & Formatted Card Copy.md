# Implementation Plan - Selectable Raid Titles & Formatted Card Copy

Enable smooth text selection for raid card titles without triggering accidental card toggles, and add a bottom-right corner copy button on expanded raid cards to copy full event details as cleanly formatted text.

## Proposed Changes

### Presentation & Styling (`style.css`)
- **Enable Text Selection on Card Titles**:
  - Update `.parent-raid-title-row .raid-title` to specify `user-select: text; -webkit-user-select: text; cursor: text;` so users can highlight and copy the title string.
- **Copy Card Contents Button**:
  - Add `.copy-raid-content-btn` styled symmetrically to `.copy-raid-link-btn` (32x32 circular button, dark/light theme background, border, glow shadow, hover scale, active feedback).
  - Position it at `bottom: -10px; right: -10px;` so it protrudes cleanly at the bottom-right corner of the expanded card.

---

### Logic & Card Rendering (`app.js`)
- **Card Title Interaction Optimization**:
  - In `renderRaids()`, track pointer drag and selection state on `.raid-title`.
  - When text is selected, dragged, or double-clicked, prevent the event from bubbling to `<summary>`, avoiding accidental card expansion or collapse during text highlighting.
  - Preserve standard single-click expansion if no text was highlighted.
- **Formatted Card Text Generator**:
  - Implement `formatRaidCardText(raid)` to convert the raid card's metadata, description, sub-events/schedules, and links into an emoji-bulleted plain text snippet ideal for sharing in messaging apps (WhatsApp, Discord, Telegram, Markdown notes).
- **Expanded Card Copy Button**:
  - Inside `bodyDiv` (`.parent-raid-body`), append `copyContentBtn`.
  - On click, copy the formatted text to clipboard via `navigator.clipboard.writeText`, toggle the icon to a checkmark for 2 seconds, and show visual feedback.

---

## Verification Plan

### Automated Tests
- Validate JS syntax using Node.js check on `app.js`.

### Manual Verification
- Open `index.html` in browser.
- Verify clicking and dragging over raid card titles highlights and selects the text without toggling the card open/close.
- Verify double-clicking a word in the title selects the word without toggling.
- Expand a raid card and verify the bottom-right copy button appears.
- Click the bottom-right copy button, paste the clipboard into a text editor, and confirm all event details, dates, venue, fees, schedule, and links are formatted accurately.
