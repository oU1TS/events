# Implementation Plan - Mobile Viewport Spacing & Mobile Auth Button Elevation

Elevate the mobile navigation auth button (`#mobile-auth-btn` / `.nav-mobile-auth-wrapper`) and introduce comprehensive dynamic viewport height (`100dvh`), `viewport-fit=cover`, and `env(safe-area-inset-bottom)` protections across mobile interface elements to eliminate clipping and overlap caused by mobile browser bottom address bars and OS gesture bars.

## Proposed User Review Required

> [!NOTE]
> No breaking changes to existing APIs or database schemas. All changes are CSS enhancements and viewport meta tag adjustments ensuring seamless mobile user experience on iOS Safari, Android Chrome, and modern mobile browsers.

## Proposed Changes

### 1. Viewport Meta Configuration
#### [`index.html`](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/events/index.html) & [`render.html`](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/events/render.html)
- Update `<meta name="viewport">` from `width=device-width, initial-scale=1.0` to `width=device-width, initial-scale=1.0, viewport-fit=cover`.
- Enables mobile Safari and Chromium browsers to expose accurate `env(safe-area-inset-bottom)` values for bottom toolbars and gesture indicators.

### 2. Mobile Sidebar & Navigation Auth Button
#### [`style.css`](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/events/style.css)
- **`.nav` Mobile Sidebar Container (`@media (max-width: 768px)`)**:
  - Replace fixed `100vh` with dynamic viewport: `height: calc(100vh - 68px); height: calc(100dvh - 68px); max-height: calc(100dvh - 68px);`.
  - Add vertical scroll support: `overflow-y: auto; -webkit-overflow-scrolling: touch; overscroll-behavior-y: contain;` for smaller devices or landscape modes.
  - Adjust flex layout from `justify-content: center` to `justify-content: flex-start` with clean gap (`1.75rem`) to prevent top cutoffs when scrolling.
  - Generous bottom container padding: `padding-bottom: calc(3.5rem + env(safe-area-inset-bottom, 24px));`.
- **`.nav-mobile-auth-wrapper`**:
  - Elevate the auth button upward by applying `padding-bottom: calc(2.5rem + env(safe-area-inset-bottom, 24px));` and `margin-bottom: 1.5rem;`.
  - Set `flex-shrink: 0;` to prevent compression during keyboard/viewport resizing.
  - Increase button touch target and active tap feedback for `.nav-mobile-auth-btn`.

### 3. Extra Spaces Where Mobile Browsers Misbehave
#### [`style.css`](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/events/style.css)
- **Floating Action Buttons (`.floating-calendar-btn`, `.floating-past-raids-btn`)**:
  - Lift floating buttons on mobile viewports so they do not clash with bottom address bars:
    - Mobile calendar button: `bottom: calc(2.25rem + env(safe-area-inset-bottom, 16px)); right: 1.25rem;`
    - Mobile past raids toggle: `bottom: calc(5.75rem + env(safe-area-inset-bottom, 16px)); right: 1.25rem;`
- **Main Dynamic Section (`.main-content`)**:
  - Mobile bottom padding increased to `calc(6.5rem + env(safe-area-inset-bottom, 24px));` so bottom cards and action cards are never masked by floating buttons or browser toolbars.
- **Global Footer (`.footer`)**:
  - Mobile bottom padding increased to `calc(4.5rem + env(safe-area-inset-bottom, 24px));`.
- **Custom Modals & Calendar Modal**:
  - Set `max-height: calc(88dvh - env(safe-area-inset-bottom, 16px));` and container safe-area bottom padding to ensure modal action buttons remain accessible even when virtual address bars appear.
- **Toast Notifications (`.toast-container`)**:
  - Safe-area bottom spacing: `bottom: calc(2.5rem + env(safe-area-inset-bottom, 20px));`.
