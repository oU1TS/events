# Implementation Plan - Raid Card Highlight Pulse De-Jank & Storage Guard

## Overview
When navigating to a direct raid card URL (e.g. `events/#raid-22`), users experienced an aggressive flicker during the card highlight animation, accompanied by browser console warnings about Tracking Prevention blocking storage for Supabase and a 404 for `favicon.ico`.

### Root Cause Analysis
1. **Background Re-Render Collision with Active Highlight**:
   Supabase contains 3 approved database proposals for Raid #22 that have subtle text differences compared to `raids.json`. When `syncApprovedSubmissionsFromDatabase()` finishes querying Supabase ~250ms after initial page load, `applyApprovedSubmissionsToDataset()` detects legitimate differences and invokes `filterAndRenderRaids()`. This completely wiped `raidsContainer.innerHTML = ''`, destroying Card #22 while its highlight pulse was in progress, and recreated the element—restarting the 3.5s animation from frame 0.
2. **Subpixel Jitter & Text Blur from `transform: scale()`**:
   `@keyframes highlightPulse` scaled the entire card geometry from `scale(1)` up to `scale(1.012)`. For a large multi-section `<details>` card, continuous subpixel scaling causes the 1px border to vibrate/strobe across device pixels and forces DirectWrite text re-rasterization every frame.
3. **Browser Tracking Prevention Blocking Supabase Storage**:
   Edge, Brave, and Safari Tracking Prevention blocks third-party CDNs (`jsdelivr.net`) from accessing `window.localStorage`, generating repeated console warnings and potential DOMExceptions during session retrieval.
4. **Missing Favicon Link**:
   Lack of an explicit `<link rel="icon">` in `index.html` causes browsers to search for `/favicon.ico` on the root domain, logging a `404 (Not Found)` error.

---

## Proposed Changes

### 1. Highlight Animation Lock (`app.js`)
- In `filterAndRenderRaids()`, check if any card is actively playing its highlight animation (`raidsContainer.querySelector('.raid-card.highlighted')`).
- If a card is currently glowing, **lock the DOM** and queue the background re-render (`pendingReRender`).
- When the 3.5s animation finishes (`animationend` or timeout fallback), seamlessly execute the queued re-render. This guarantees the highlight pulse is **never interrupted or restarted mid-stride**.

### 2. Pure Luminous Glow Animation (`style.css`)
- Remove all `transform: scale(...)` from `@keyframes highlightPulse`.
- Remove `backface-visibility: hidden` and `will-change: transform`.
- Keep the pulse strictly focused on breathing `box-shadow` (radiance) and `border-color`. This eliminates all subpixel border strobing, text blurring, and grid layout reflows.

### 3. Safe Storage Adapter for Supabase (`app.js`)
- Provide a resilient in-memory fallback storage adapter for `supabaseClient` (`auth: { storage: safeStorage }`) to catch any `SecurityError` or Tracking Prevention blocks silently.
- Wrap all direct `localStorage` reads/writes in `try/catch` guards.

### 4. SVG Favicon Integration (`index.html`)
- Add an inline SVG data URI favicon in `index.html` featuring the gold Event Raiders sword/shield icon to resolve the `/favicon.ico` 404 error.
