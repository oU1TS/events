# Walkthrough - Mobile Viewport Spacing & Mobile Auth Button Elevation

Elevated the mobile sidebar auth button (`#mobile-auth-btn` in `.nav-mobile-auth-wrapper`) and integrated dynamic viewport height units (`100dvh`), `viewport-fit=cover`, and `env(safe-area-inset-bottom)` clearances to eliminate overlap issues caused by mobile browser bottom address bars and OS gesture indicators.

## Summary of Changes

### 1. Mobile Sidebar Navigation (`#main-nav` / `.nav`)
- **Dynamic Viewport Height**: Replaced fixed `height: calc(100vh - 68px)` with modern dynamic viewport height:
  ```css
  height: calc(100vh - 68px);
  height: calc(100dvh - 68px);
  max-height: calc(100dvh - 68px);
  ```
  This automatically adapts the menu height when the browser's bottom URL bar or toolbars expand or retract.
- **Scroll & Overscroll Containment**: Added `overflow-y: auto`, `-webkit-overflow-scrolling: touch`, and `overscroll-behavior-y: contain` so navigation stays cleanly scrollable without trapped scroll or clipped buttons on compact devices or landscape orientations.
- **Clean Flex Alignment**: Shifted layout from `justify-content: center` to `justify-content: flex-start` with consistent gaps, preventing top link cutoff when content overflows.

### 2. Mobile Auth Button Wrapper (`.nav-mobile-auth-wrapper` & `#mobile-auth-btn`)
- **Elevated Bottom Margin & Padding**: Lifted the auth wrapper upward from the bottom of the viewport:
  ```css
  .nav-mobile-auth-wrapper {
      padding-bottom: calc(2.5rem + env(safe-area-inset-bottom, 24px));
      margin-bottom: 1.5rem;
      border-top: 1px solid var(--border-color);
      flex-shrink: 0;
      box-sizing: border-box;
  }
  ```
- **Touch-Friendly Hit Target**: Added `min-height: 48px`, `border-radius: 12px`, `touch-action: manipulation`, and active tap feedback (`transform: translateY(-2px)` with subtle accent glow) to `.nav-mobile-auth-btn`.

### 3. Extra Spaces Where Mobile Browsers Misbehave
- **`viewport-fit=cover` Enabled**: Updated `<meta name="viewport">` in [`index.html`](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/events/index.html) and [`render.html`](file:///c:/Users/gsmur/OneDrive/Documents/GitHub/events/render.html) to enable iOS Safari and Chromium mobile to provide accurate `env(safe-area-inset-bottom)` coordinates.
- **Floating Action Buttons**: Elevated `.floating-calendar-btn` and `.floating-past-raids-btn` on mobile:
  - Calendar button: `bottom: calc(2.25rem + env(safe-area-inset-bottom, 16px)); right: 1.25rem;`
  - Past raids toggle: `bottom: calc(5.75rem + env(safe-area-inset-bottom, 16px)); right: 1.25rem;`
  - Fallback safe-area support added for base desktop floating buttons.
- **Main Content & Footer Spacing**:
  - `.main-content` on mobile: `padding-bottom: calc(6.5rem + env(safe-area-inset-bottom, 24px))` ensures the bottom raid card is never obstructed by floating controls or browser chrome.
  - `.footer` on mobile: `padding: 2.5rem 1.5rem calc(4.5rem + env(safe-area-inset-bottom, 24px)) 1.5rem`.
- **Modals & Toast Clearances**:
  - `.custom-modal`, `.custom-modal-content`, `.calendar-modal`, and `.calendar-modal-content` capped to `calc(88dvh - env(safe-area-inset-bottom, 16px))` with safe-area padding.
  - `.toast-container` elevated to `bottom: calc(2.25rem + env(safe-area-inset-bottom, 20px))` on mobile.
