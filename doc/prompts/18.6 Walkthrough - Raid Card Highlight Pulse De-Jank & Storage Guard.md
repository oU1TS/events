# Walkthrough - Raid Card Highlight Pulse De-Jank & Storage Guard

We have completely identified and resolved all sources of highlight animation flicker, subpixel jitter, premature cancellation, and console storage warnings.

---

## 🔍 Root Cause Breakdown & Empirical Findings

Through headless Chrome Selenium instrumentation and DOM MutationObserver tracking, we uncovered the exact sequence of events causing the animation flicker:

1. **Child `animationend` Event Bubbling Prematurely Terminating Highlight Pulse**:
   - In DOM specifications, `animationend` events bubble up the DOM tree.
   - When Card #22 opened (`card.open = true`), its inner container `.parent-raid-body` ran its entry transition:
     `animation: parentFadeIn 0.3s cubic-bezier(...)`.
   - At `~193ms` into the page lifecycle, `parentFadeIn` finished. Its `animationend` event bubbled up to `<details class="raid-card parent-raid-card">`.
   - The card's `card.addEventListener('animationend', ...)` listener was **un-guarded** (it did not verify `e.target === card` or `e.animationName === 'highlightPulse'`).
   - Consequently, the listener caught the child's `parentFadeIn` completion, mistook it for the end of `highlightPulse`, removed `.highlighted` after only 193ms, and immediately flushed `pendingReRender()`.
   - `pendingReRender()` wiped the DOM (`raidsContainer.innerHTML = ''`), destroying and recreating all cards right as the user was looking at the card. This produced the violent visible flicker!

2. **Scroll Offset Clipping Card Header Behind Fixed Navbar**:
   - `card.scrollIntoView({ behavior: 'smooth', block: 'center' })` attempts to center an ~891px tall open card within an ~800px viewport.
   - Because `cardHeight > viewportHeight`, centering scrolled the top of the card off-screen above the viewport (`top: -120px` to `-150px`), hiding the title, badges, and copy buttons behind the sticky navbar.

3. **Subpixel Jitter & Text Blur from `transform: scale()`**:
   - `@keyframes highlightPulse` scaled the entire card geometry from `scale(1)` up to `scale(1.012)`. For a multi-section card with nested borders, continuous subpixel scaling caused the 1px border to vibrate/strobe across device pixels and forced text re-rasterization.

4. **Browser Tracking Prevention Blocking Supabase Storage**:
   - Edge, Brave, and Safari Tracking Prevention blocks third-party CDNs from accessing `window.localStorage`, generating repeated console warnings during session retrieval.

5. **Missing Favicon Link**:
   - Lack of an explicit `<link rel="icon">` in `index.html` caused browsers to search for `/favicon.ico` on the root domain, logging a `404 (Not Found)` error.

## 🛠️ Changes Implemented

### 1. Guarded `animationend` Listeners ([`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js))
In `scrollToRaid()` and `renderRaids()`, guarded `animationend` against bubbling events from child elements:
```javascript
const onAnimationEnd = (e) => {
    // Ensure the event originated directly from the card and corresponds to highlightPulse
    if (e.target !== card || e.animationName !== 'highlightPulse') return;
    card.removeEventListener('animationend', onAnimationEnd);
    card.classList.remove('highlighted');
    if (activeHighlightTimeout) {
        clearTimeout(activeHighlightTimeout);
        activeHighlightTimeout = null;
    }
    if (pendingReRender) {
        const fn = pendingReRender;
        pendingReRender = null;
        fn();
    }
};
card.addEventListener('animationend', onAnimationEnd);
```

### 2. Sticky Navbar Clearance & Smooth Align ([`style.css`](file:///d:/GitHub/[oU1TS]/events/style.css) & [`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js))


### 3. Highlight Animation Lock ([`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js))
In `filterAndRenderRaids()`, added a lock that queues database re-renders while a card is actively glowing:
```javascript
let pendingReRender = null;

function filterAndRenderRaids(options = {}) {
    if (!pastRaidsData) return;

    // If a raid card is actively undergoing its highlight pulse, lock the DOM and queue re-render
    const raidsContainer = document.getElementById('raids-container');
    if (!options.forceImmediate && raidsContainer && raidsContainer.querySelector('.raid-card.highlighted')) {
        pendingReRender = () => filterAndRenderRaids({ forceImmediate: true });
        return;
    }
    ...
```

### 5. Safe Storage Adapter for Supabase ([`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js))
Provided safe in-memory fallback adapter:
```javascript
const memoryStorage = {};
const safeStorage = {
    getItem: (key) => {
        try { return window.localStorage.getItem(key); } catch (e) { return memoryStorage[key] || null; }
    },
    setItem: (key, value) => {
        try { window.localStorage.setItem(key, value); } catch (e) { memoryStorage[key] = value; }
    },
    removeItem: (key) => {
        try { window.localStorage.removeItem(key); } catch (e) { delete memoryStorage[key]; }
    }
};
```

### 6. Inline SVG Favicon Integration ([`index.html`](file:///d:/GitHub/[oU1TS]/events/index.html))
Added inline SVG favicon in `<head>` to prevent root domain 404s.
