# 18.9 Implementation Plan — Slug Deep Link No-Expand & Anti-Flicker Hardening

## 🎯 Objective

Verify and harden the deep link slug feature (`#raid-N` URL → scroll to card + faint glow) so that:
1. Cards are **never force-expanded** when navigating via a slug URL.
2. The glow animation is **never flickery** due to competing CSS transitions or missing GPU compositing hints.

---

## 🔍 Issues Found in Audit

### Issue 1: `scrollToRaid()` force-opened `<details>` card  
**File:** `app.js` lines 200–203 (pre-fix)  
**Problem:** `scrollToRaid()` unconditionally set `card.open = true` before scrolling. The user requested that visiting `#raid-N` only scrolls and glows — no auto-expansion.

### Issue 2: `renderRaids()` auto-opened targeted card on initial render  
**File:** `app.js` `renderRaids()`, `card.open` logic (pre-fix)  
**Problem:** On first render, the card matching `#raid-N` or `pendingRaidScroll` was forced open via `card.open = openCardIds.has(card.id) || isTargetedRaid`. Same problem.

### Issue 3: `transition: none !important` dropped from `.raid-card.highlighted`  
**File:** `style.css` `.raid-card.highlighted` rule (pre-fix)  
**Problem:** Previously added in session 18.3/18.4, this critical rule was absent. Without it, the base `.raid-card` transition (`transform 0.3s, border-color 0.3s, box-shadow 0.3s`) competes with `@keyframes highlightPulse`, causing subpixel paint jank on the initial frames of the glow.

### Issue 4: `will-change` and `backface-visibility` missing  
**File:** `style.css` `.raid-card.highlighted` rule (pre-fix)  
**Problem:** GPU compositing hints also dropped. These promote the card to its own compositing layer, ensuring the box-shadow animation is painted without layout reflows.

---

## ✅ Changes Applied

### `app.js` — Remove card auto-open from `scrollToRaid()`
```js
// BEFORE
if (card.tagName.toLowerCase() === 'details' && !card.open) {
    isProgrammaticScrollOpening = true;
    card.open = true;
    setTimeout(() => { isProgrammaticScrollOpening = false; }, 80);
}
card.scrollIntoView({ behavior: 'smooth', block: 'start' });

// AFTER
card.scrollIntoView({ behavior: 'smooth', block: 'start' });
// (no force-open; card stays in whatever state it was)
```

### `app.js` — Remove auto-open from `renderRaids()` initial render
```js
// BEFORE
if (hasRenderedBefore) {
    card.open = openCardIds.has(card.id);
} else {
    const isTargetedRaid = (pendingRaidScroll === raid.Raid_Num) ||
        (window.location.hash === `#raid-${raid.Raid_Num}`);
    card.open = openCardIds.has(card.id) || isTargetedRaid;
}

// AFTER
// Never force-open from URL slug — slugs are scroll+glow only.
card.open = openCardIds.has(card.id);
```

### `style.css` — Restore anti-flicker properties on `.raid-card.highlighted`
```css
/* BEFORE */
.raid-card.highlighted {
    animation: highlightPulse 2.1s cubic-bezier(0.22, 1, 0.36, 1) forwards;
    z-index: 10;
    border-color: var(--accent) !important;
}

/* AFTER */
.raid-card.highlighted {
    transition: none !important;
    animation: highlightPulse 2.1s cubic-bezier(0.22, 1, 0.36, 1) forwards;
    z-index: 10;
    border-color: var(--accent) !important;
    will-change: box-shadow;
    backface-visibility: hidden;
    -webkit-backface-visibility: hidden;
}
```
