# Walkthrough - Selectable Raid Titles & Formatted Card Copy

We have implemented selectable raid card titles and added a formatted text copy button at the bottom-right corner of each expanded raid card.

## Changes Overview

### 1. Selectable Card Titles (`style.css` & `app.js`)
- **CSS Selection Enabled**: Applied `user-select: text; -webkit-user-select: text; cursor: text;` to `.parent-raid-title-row .raid-title`.
- **Accidental Toggle Prevention**:
  - Implemented pointer drag and double-click detection in `app.js`.
  - When users drag to select title text or double-click to highlight words, `e.stopPropagation()` and `e.preventDefault()` prevent the click from bubbling to `<summary>`, keeping the card open or closed without jarring toggles.
  - A clean single click with no drag or selection still smoothly toggles the card.

### 2. Expanded Card Copy Button (`style.css` & `app.js`)
- **Bottom-Right Corner Positioning**:
  - Designed `.copy-raid-content-btn` as a 32x32 circular button matching the aesthetic of the top-right copy link button.
  - Positioned at `bottom: -10px; right: -10px;` so it protrudes cleanly at the bottom-right corner of the expanded card.
  - Appended inside `bodyDiv` (`.parent-raid-body`), ensuring it is **only displayed when the card is expanded**.
- **Formatted Plain-Text Summary (`formatRaidCardText`)**:
  - Formats event details cleanly for messaging apps (WhatsApp, Discord, Telegram, Markdown notes):
    - 🏆 Event Title & Raid Number
    - 📅 Date, 🏷️ Type, ⚡ Status, 📍 Venue, 💰 Fees, ⏳ Registration Deadline
    - 📝 Description / Overview
    - 🗓️ Sub-events & Schedule
    - 🔗 External Links (including full Notes viewer URL)
    - 🌐 Direct Event Raiders link
- **Visual Feedback**:
  - Clicking transitions the icon to a checkmark for 2 seconds with an accent color background, matching the site's interaction feedback pattern.
