# Walkthrough: 15. Calendar Initial Month & Approved Raid Persistence

## Overview of Changes

1. **Dynamic Calendar Initial Month Alignment**:
   - Fixed the Campaign Calendar modal defaulting to a hardcoded July 2026.
   - Initialized `calendarYear` and `calendarMonth` dynamically from `new Date()` in `initCalendar()`.
   - Updated `openModalWithData()` so that clicking the static `#open-calendar-btn` or the floating `#floating-calendar-btn` resets the calendar view to the active current month and year.
   - Exposed `window.renderCalendarGrid` globally so external data sync events can dynamically refresh calendar dates.

2. **Database Approved Raid Live Sync & Persistence**:
   - Approving a proposal in the Review Dashboard updates `public.event_submissions` with `status: 'approved'` and immediately saves it to `localStorage` (`event_raids_approved_cache`).
   - Added `applyApprovedSubmissionsToDataset(submissions)` to merge approved items into `pastRaidsData` (updating existing records or prepending new ones) and sort them by `Raid_Num` in descending order.
   - Added `applyCachedApprovedSubmissions()` to load cached approved submissions instantly on page boot without waiting for network or authentication calls.
   - Added `syncApprovedSubmissionsFromDatabase()`:
     - Fetches approved rows (`status = 'approved'`) from Supabase in the background.
     - Updates `event_raids_approved_cache`.
     - Automatically re-renders the raid cards, campaign calendar, and event notes when new database additions are detected.
   - Triggered sync during `loadPastRaids()` and inside `syncAuthState()`.
   - Updated `rejectSubmission()` to cleanly purge rejected entries from `event_raids_approved_cache` if they were previously approved.

3. **Pre-Compiled Raid #21 ("Bangladesh AI Business Summit 2026")**:
   - Added Raid #21 into [`raids.json`](file:///d:/GitHub/[oU1TS]/events/raids.json) with complete metadata (Nov 5, 2026 at BBCFEC Dhaka, Conferences / Webinars, Free).
   - Updated [`tracker.json`](file:///d:/GitHub/[oU1TS]/events/tracker.json) (`eventsCount: 21` and reminder entry for Nov 5, 2026).
   - Re-compiled [`feed.xml`](file:///d:/GitHub/[oU1TS]/events/feed.xml) with the latest active events.

4. **Public RLS Policy for Approved Submissions**:
   - Updated [`doc/db/event_raids_schema.sql`](file:///d:/GitHub/[oU1TS]/events/doc/db/event_raids_schema.sql) with a public SELECT policy:
     ```sql
     DROP POLICY IF EXISTS "Public can view approved submissions" ON public.event_submissions;
     CREATE POLICY "Public can view approved submissions" ON public.event_submissions
         FOR SELECT
         USING (status = 'approved');
     ```
