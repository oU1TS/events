# Implementation Plan: 15.3 Proposal Event Types & Custom Links Repeater

Synchronize the Event Proposal Modal (`#event-form-modal`) category options with the Roadmap filter dropdown and add a dynamic Custom Links and Documents repeater to support image links, brochures, rulebooks, and external resources.

---

## Proposed Changes

### 1. Synchronize Event Types in `#event-form-modal`
- **File**: [`index.html`](file:///d:/GitHub/[oU1TS]/events/index.html)
- **Problem**: `#form-type` only offered a limited subset of types, missing `Congress`, `Bug Bounties / CTF`, `Expos / Fairs`, `Idea & Bizcomps`, and `Olympiad / Carnival`.
- **Solution**:
  - Update `#form-type` options to include all 8 filter dropdown categories (`Hackathons`, `Contests`, `Conferences / Webinars`, `Congress`, `Bug Bounties / CTF`, `Expos / Fairs`, `Idea & Bizcomps`, `Olympiad / Carnival`) alongside supplementary types (`Showcases`, `Bootcamps / Workshops`, `Academic`, `Other`).
  - In `app.js` (`populateFormFromRaidObject`), ensure custom or legacy event types not yet in `<select>` are dynamically added as `<option>` to prevent data loss.

### 2. Custom Links & Documents Repeater
- **Files**: [`index.html`](file:///d:/GitHub/[oU1TS]/events/index.html), [`style.css`](file:///d:/GitHub/[oU1TS]/events/style.css), [`app.js`](file:///d:/GitHub/[oU1TS]/events/app.js)
- **Problem**: Lines 977-999 currently only offer static fields for Event Website, Registration, Facebook, and local Notes path. Users cannot add custom image links (e.g. Banner / Poster), brochures, PDF rulebooks, Google Drive links, or other resources.
- **Solution**:
  - In `index.html`:
    - Add a header button `+ Add Custom Link / Document` (`#add-custom-link-btn`) to the "Official Links & Resources" sub-section.
    - Add `#custom-links-repeater` container below the static inputs.
    - Add `<datalist id="custom-link-preset-suggestions">` for quick label recommendations (e.g. *Poster / Image*, *Rulebook (PDF)*, *Brochure*, *Discord*, *WhatsApp Group*, *Drive Folder*, *Presentation Slides*).
  - In `style.css`:
    - Style `.custom-links-repeater`, `.custom-link-row`, `.custom-link-name-input`, `.custom-link-url-input`, and `.remove-custom-link-btn` with responsive collapse on screens `< 640px`.
  - In `app.js`:
    - Implement `addCustomLinkRow(name = '', url = '')` with name, URL, and remove handlers.
    - Implement `collectLinksFromForm()` to serialize both primary links and all dynamic custom link rows into the raid's `links` map.
    - Update `getRaidObjectFromForm()` and form submission handler to use `collectLinksFromForm()`.
    - Update `populateFormFromRaidObject(data)` to populate primary links and dynamically spawn custom link rows for any additional link properties.
    - Update `openEventFormModal()` to clear `#custom-links-repeater` on new proposals.
    - Update `buildNewRaidSummary()` in Review Dashboard to display all links including custom image/document links.
