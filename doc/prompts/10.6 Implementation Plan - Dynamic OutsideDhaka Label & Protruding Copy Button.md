Enhance the **OutsideDhaka** venue badge with a dynamic 2-second toggle animation linked to Google Maps, and relocate the card **Copy Link** button to protrude cleanly outside the top-right corner of each raid card.

### Application Logic & Presentation Layer

#### [MODIFY] [app.js](file:///c:/Users/.../Documents/GitHub/[oU1TS]/events/app.js)
1. **Dynamic OutsideDhaka Label & Google Maps Integration**:
   - Render `.outside-dhaka-tag` as an `<a>` element linking directly to Google Maps (`https://www.google.com/maps/search/?api=1&query=${encodeURIComponent(raid.venue)}`).
   - Add `e.stopPropagation()` to prevent expanding/collapsing the card when clicking the map link.
   - Implement a dynamic 2-second interval (`setInterval`) or CSS pulse transition that seamlessly toggles the label content between:

2. **Relocate Copy Link Button**:
   - Move `.copy-raid-link-btn` from `.raid-meta-right` directly to top-level inside `card`.
   - Add `e.stopPropagation()` and `e.preventDefault()` to copy the deep-link URL without toggling card collapse state.
